# Patterns Index

Each pattern lives in its own reference file. Load only the file relevant to the task at hand.

| Pattern | File | When to load |
|---|---|---|
| Component → Action → API Flow | `references/component-flow.md` | Any feature implementation, mutation, or data fetch |
| Routing | `references/routing.md` | Adding or modifying routes, route structure questions |
| Loader Pattern | `references/loader-pattern.md` | Pre-fetching data for a route, deferred loading, Suspense/Await |
| Form Validation | `references/form-validation.md` | Any form with validation (Zod + react-hook-form) |
| Context Pattern | `references/context-pattern.md` | Global or subtree-shared state, when to use Context vs Zustand |
| Custom Hooks | `references/custom-hooks.md` | Creating or reviewing action hooks or common hooks |
| Auth Pattern | `references/auth-pattern.md` | Login, logout, protected routes, token refresh, AuthContext |
| Vite Config & tsconfig | `references/vite-config.md` | Project setup, alias config, Tailwind installation |
| Anti-Patterns | `references/anti-patterns.md` | Refactor tasks, design errors, or structural code review |
| Action Folder Subdivision | `references/actions.md` | `adapters/hooks/actions/` growing large, organizing action hooks by domain |
